# v0.2.45

## BrowserResearch first-run reliability

- Desktop packages already contain the managed Chromium runtime; BrowserResearch now recognizes that packaged runtime before the user-specific runtime folder has been created.
- On a clean computer, BrowserResearch is included in the first Expert Mode tool list instead of being hidden as unavailable.
- The first BrowserResearch call still seeds the managed Chromium runtime into the user's app storage, without replacing an existing local runtime.

## Included platform behavior

- Windows and macOS desktop packages both retain their platform-specific bundled Chromium resource.
- This release does not change workflow packs, Expert ZIP content, or user-imported packages.
