# Claude Code Jiangxia v0.2.42

## Built-in BrowserResearch runtime

- Desktop installers now include a managed Chromium Headless Shell for BrowserResearch.
- On first BrowserResearch use, the app seeds that runtime into the current user profile at `~/.claude/cc-jiangxia/browser-runtime/playwright`.
- Existing usable local browser runtimes are preserved instead of overwritten.
- Windows builds package the Windows x64 runtime; macOS Apple Silicon builds package the macOS ARM64 runtime.

## Commercialization Research Expert

- Updated the bundled `新品商业化调研报告专家` pack to `0.10.9-local`.
- Added the package-local `external-demand-evidence` Skill, so the ZIP itself requires independent, traceable external user-demand evidence.
- Search, topic, category, and listing pages are treated only as discovery entry points; final demand, pain-point, migration, or payment claims must trace to reviewed concrete content pages or user-provided primary material.
- The Expert now prioritizes commercialization method, source-graph research, and external-demand evidence before downstream market and strategy analysis.
