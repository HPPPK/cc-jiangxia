# Claude Code Jiangxia v0.2.56

## Added

- Feature Extension and Debug Repair workflow packs now create a complete inventory for every request in one conversation. Independent tasks may run as parallel batches when their dependencies, write scopes, shared resources, and risks are isolated.

## Improved

- Each individual task still keeps implementation and review in order: Coder, Reviewer, then only bounded follow-up fixes.
- Workflow tool policy now blocks unsupported Computer Use actions before execution instead of letting a workflow attempt an unavailable action.
- Required bounded decisions can recover to an AskUserQuestion card instead of leaving the user with a prose-only choice.
- The desktop development app can locate its bundled Playwright browser runtime from the Tauri development binaries.

## Distribution note

- This release includes the current Feature Extension and Debug Repair workflow packs.
- The new uncommitted Commercialization Research Expert changes are intentionally not included in this release.
- The UI/UX design-system Expert Pack remains excluded from the public bundle.
