# v0.2.48

## Commercialization research Expert

- Expert Mode now always removes the unavailable WebSearch tool and uses BrowserResearch-first candidate URL research instead.
- BrowserResearch evidence requires a successfully opened page; candidate URLs alone are not treated as evidence.
- When browser evidence is unavailable after reasonable attempts, the Expert asks the user to provide material, accept the evidence gap, or explicitly approve a WebFetch fallback for the failed URL.
- The commercialization research Expert now produces structured report fields that are rendered through the authoritative template before the generic Write tool saves the final HTML.
- Bundled Expert ZIP import and listing reject incomplete packs with a clear missing-Skill error.

## Pack delivery

- Rebuilt the bundled commercialization-research-report ZIP from the latest Expert source before packaging.
- Workflow ZIPs are unchanged in this release.
