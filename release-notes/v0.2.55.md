# Claude Code Jiangxia v0.2.55

## Added

- The UI/UX design-system Expert is bundled with the desktop application and its current research and visual-QA Skills.
- Commercialization research Expert reports can use the fixed template-fill path, preserving the shared Write tool for ordinary file writes.

## Improved

- Image attachments are retained when a selected model's image capability is unknown; they are removed only when the model is confirmed not to support images.
- Bundled Workflow Packs now allow the host runtime to schedule independent, non-overlapping batches without an artificial numeric concurrency cap. Per-batch dependency order, write-scope isolation, and exclusive-resource protection remain enforced.
- Updated the bundled Development, Feature Extension, Debug Repair, Commercialization Research, and UI/UX Expert Packs.

## Fixed

- Expert runtime session state and structured report output now remain available through the intended CLI, server, and desktop paths.
