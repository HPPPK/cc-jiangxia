# Claude Code Jiangxia v0.2.58

## 工作流与上下文

- 引导式产品开发、功能拓展与 Debug 工作流会优先使用当前请求、所选工作区和恢复会话上下文；存在 `.workflow` 项目资料时才作为补充读取，不再让固定文件名主导首阶段。
- 功能拓展与 Debug 保留必要问题与回答影响说明，但不会因为上一张问题卡尚待阶段处理而阻断下一张必要问题卡。
- 工作流问题、阶段转换和会话恢复的错误反馈更明确，完成/代码变更摘要会按会话模式在合适的完成节点显示。

## 浏览器研究与桌面运行时

- BrowserResearch 在普通对话、工作流和专家会话中的使用指引与运行时判断得到统一；搜索链接会被规范化、筛选和评估，避免把搜索页或不安全 URL 当作最终证据。
- Windows 桌面包会携带 BrowserResearch 所需的受控 Playwright Node runner，并继续使用内置浏览器运行时。
- 桌面构建、启动说明和本地运行时处理得到完善。

## 新品商业化调研专家

- 更新内置的 `commercialization-research-report` 专家包（v0.11.2-local）。
- 强化真实外部需求、来源图谱、浏览器取证、渠道证据、假设与市场规模表达规则；来源不足时明确给出最低成本验证路径，而不伪造数据。
- 专家报告字段写入、导入/完整性校验与运行时绑定错误提示更加可靠。

## 打包内容

- 引导式产品开发流程
