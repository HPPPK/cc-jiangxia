# v0.2.44

## Windows runtime reliability

- Windows installer packages now include a managed Portable Git runtime containing both Git and Git Bash.
- Existing system Git / Git Bash remains preferred. The packaged runtime is used only when the computer does not provide a usable installation.
- Workflow Git checkpoints no longer return a server error solely because git is unavailable; when neither system nor packaged Git is available, checkpoints are disabled safely.
- Desktop server startup now initializes the packaged Git Bash fallback before Bash tool execution, preventing the No suitable shell found failure on clean Windows machines.

## Product research expert

- Updated the built-in 新品商业化调研报告专家 product-manager pack.
- All 16 declared Skills are embedded at the runtime path skills/<skillId>/SKILL.md.
- Incomplete expert ZIPs are rejected before import or selection with a clear missing-Skill message instead of an unexpected error.

## Platform compatibility

- macOS packaging remains compatible: Windows Portable Git is neither downloaded nor used by macOS builds.
