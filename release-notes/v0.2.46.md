# v0.2.46

## Windows project-runtime readiness

- Windows desktop packages now include a validated Node.js runtime for generated projects.
- Agent Bash commands can use `node`, `npm`, and `npx` immediately on a clean Windows computer without a system-wide Node.js installation, `winget`, administrator privileges, or a global PATH change.
- The packaged Node runtime is exposed only to desktop child processes, so parallel workflow agents share the same ready runtime instead of independently trying to install Node.

## Commercialization research Expert

- The bundled commercialization research Expert now includes 17 package-local Skills.
- Added `channel-acquisition-evidence`: it distinguishes first-party product facts, external content/community signals, and evidence gaps before making SEO, SEM, or acquisition-channel recommendations.
- A single content page cannot by itself prove an acquisition channel is effective; negative observations such as “not found” require an actual page, SERP, or screenshot observation.
- The updated Expert ZIP is self-contained and carries the new channel-evidence Skill into fresh desktop installations.

## Platform scope

- This release adds the managed Node runtime for Windows project commands. macOS packaging behavior and its existing bundled resources are unchanged.
