# Claude Code Jiangxia v0.2.43

## Expert output template enforcement

- Restored Write as a general-purpose file-writing tool; it no longer carries commercialization-report HTML rules for every use.
- Added an Expert-only pre-execution policy for the commercialization-research report template.
- When that Expert session has template protection enabled, non-conforming HTML is rejected before any file is written, with the explicit error code EXPERT_OUTPUT_TEMPLATE_REJECTED.
- Ordinary Write usage, other Experts, and non-HTML files are not affected by this specialized rule.
