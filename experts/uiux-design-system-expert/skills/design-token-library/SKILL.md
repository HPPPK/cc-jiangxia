# Design Token Library

## v0.1 风格方向（12 类）
编辑型、企业工具型、数据密度型、温和服务型、精品电商型、内容阅读型、医疗可信型、教育引导型、金融稳健型、开发者工具型、生活方式型、极简品牌型。

## v0.1 色板方向（12 类）
墨蓝可信、森林自然、暖橙行动、岩灰专业、雾紫创意、海盐清爽、沙漠温暖、莓果柔和、石墨高对比、晨光明亮、青绿健康、午夜深色。

先定义语义 Token：color.bg、color.surface、color.text、color.action、color.status、space、radius、shadow、motion、font。

组件至少说明默认、hover、focus、disabled、loading、empty、error、success 状态。任何风格推荐都要给出适配理由、风险和替代方向。
