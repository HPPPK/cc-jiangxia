# Accessible HTML Prototype

- 生成单文件 HTML 时，用 CSS 变量承载颜色、间距、圆角、阴影、字号和动效 Token。
- 使用 main、nav、header、section、button、label、input 等语义元素；不要用纯 div 假装按钮。
- 所有交互控件可键盘访问，有 focus-visible 样式，状态不只依赖颜色。
- 保持正文与背景的可读对比；对数据、价格和错误状态提供文本信息。
- 在 320px、768px 和桌面宽度检查布局；不要假设桌面结构能直接缩小到手机。
- 原型末尾注明：这是交互/视觉假设，不是已完成的用户验证。
