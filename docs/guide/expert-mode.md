# 专家 Mode

专家 Mode 是桌面端的“按专家包工作”能力。它适合把一套可复用的角色、提示词、Skills、表单、输出模板和工具说明封装为一个专家，再在聊天会话中按该专家的约束工作。

## 开始使用

1. 在桌面端先打开或新建一个聊天会话。
2. 在输入框旁打开专家选择器，选择需要的专家。
3. 系统会进入专家 Mode，并向聊天发送一条可见的欢迎问题；专家提示词、Skills 和模板会由服务端隐式注入，不会作为用户消息显示在聊天记录中。
4. 直接输入任务背景、产品方向，或上传你希望专家参考的资料。

进入专家 Mode 不代表模型拥有额外的电脑或网络权限。每一轮实际可用工具仍由当前桌面端运行时决定。

## 专家包包含什么

一个专家包是可导入、可导出的 ZIP。其源码包可包含：

- 专家定义、简介、分类和标签；
- 系统提示词与可选的收集表单；
- 专家专用 Skills；
- 工具声明与权限说明；
- 可选的输出协议和固定 HTML 模板。

在“专家”设置中可以查看、导入、导出、编辑专家包，并管理分类、专家资料和提示内容。分类是可配置数据，不要求固定为某几个类别。

## 工具与网页研究

专家包会声明它建议使用的工具；运行时只会向模型展示当前真实可用的工具。包里的声明不会凭空启用一个不存在的工具，也不会绕过普通权限控制。

需要公开网页证据的专家应优先使用 **BrowserResearch**。它通过本机受管 Chromium/Playwright 打开网页，向模型返回可见文字、实际链接、截图路径以及受限或失败原因。

- 网页要求登录、验证码、地区限制、robots 或限流时，应记录为访问受限；
- 不应把无法访问的网站内容当成已验证事实；
- 在当前模型或运行时没有网页发现能力时，专家会要求你提供链接、截图、导出的页面或内部资料；
- BrowserResearch 不保证任何第三方网站都允许自动访问，仍需遵守网站条款和适用规则。

## Skills 发现

专家管理页可以搜索公开的 Skill 链接，包括 QClaw 来源。该功能只返回公开链接，不会自动下载、导入或执行第三方 Skill。

在线搜索依赖你在 Web Search 设置中配置 Tavily 或 Brave 的 API Key。没有配置时，界面会明确提示配置缺失；这不影响已安装专家包的本地使用。

## 商业化调研报告专家

随第一版提供的“新品商业化调研报告专家”包含：业务规则输入、研究方法 Skills、竞品/需求/渠道子代理、独立证据复核、固定 HTML 母版和报告输出约束。

使用时建议：

1. 提供产品方向、市场范围、首发平台和已有资料；
2. 让专家先提出需要确认的问题；
3. 审阅研究结论、证据缺口和待验证假设；
4. 确认输出路径后，再让专家写入最终 HTML 报告。

固定 HTML 母版用于保持报告结构一致。没有足够证据时，报告应保留“待验证”“假设”或“证据缺口”，而不是将推测写成确定结论。

## 已知边界

- 专家包中的提示词和 Skills 会约束模型行为，但不能替代对事实的人工复核；
- 子代理和证据复核的结果需要在最终报告中被正确采纳，来源数量不等于来源多样性；
- 历史会话如果没有成功保存专家运行时绑定，不能被安全地当作仍处于专家 Mode；新版本会在进入专家 Mode 时校验该绑定是否已持久化；
- 报告写入本机文件前，仍应确认目标目录和输出文件名。
